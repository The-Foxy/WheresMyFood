# راه‌اندازی یک‌بارهٔ آپدیت خودکار «غذام کو؟»

نسخهٔ انتشار: **۱٫۱٫۰**

این بسته اسکریپت کمکی آپدیت خودکار را برای همهٔ مرورگرهای کرومیوم (**Chrome، Edge، Brave و Chromium**) یک‌جا تنظیم می‌کند. برنامهٔ دائمی در پس‌زمینه، سرور محلی، دسترسی Administrator/sudo یا Git لازم نیست؛ مرورگر هر ۶ ساعت اسکریپت را اجرا می‌کند.

## نصب سریع برای کاربر (فقط یک بار)

۱. فایل `wheresmyfood-setup.zip` را از بخش Releases ریپازیتوری بگیر و Extract کن.

۲. مطابق سیستم‌عاملت فایل نصاب را اجرا کن:

- **ویندوز:** روی فایل **`Install-Windows.bat`** دابل‌کلیک کن (اگر Python 3.10+ نصب نباشد، خودش پیشنهاد نصب خودکار با `winget` را می‌دهد).
- **مک (macOS):** روی فایل **`Install-macOS.command`** دابل‌کلیک کن.
- **لینوکس:** فایل `./install-linux.sh` یا دستور `python3 updater/install.py` را اجرا کن.

۳. بعد از اجرای نصاب، مسیر پوشهٔ `extension` خودکار داخل کلیپ‌بورد کپی می‌شود و صفحهٔ راهنمای تصویری (`setup-guide.html`) همراه با پوشه باز می‌شود:

- در مرورگر وارد `chrome://extensions` (یا `edge://extensions`) شو و کلید **Developer mode** را روشن کن.
- دکمهٔ **Load unpacked** را بزن، با **Ctrl+V** مسیر کپی‌شده را جای‌گذاری کن و پوشهٔ `extension` را انتخاب کن (یا پوشهٔ `extension` را مستقیم با موس بکش و وسط صفحهٔ Extensions رها کن).
- اگر نسخهٔ قدیمی نصب است خاموشش کن و تب `snappfood.ir` را یک بار Refresh کن.

از این به بعد دریافت، بررسی سلامت بسته، جایگزینی و Reload افزونه کاملاً خودکار است. اجرای دوبارهٔ نصاب هم امن است و بدون دانگرید نسخهٔ نصب‌شده، اتصال مرورگرها را تعمیر می‌کند.

## سازوکار و حدود دسترسی

- تنها منبع آپدیت: Release پایدار `The-Foxy/WheresMyFood` با فایل `snappfood-assistant.zip` (تگ نسخه باید با `manifest.json` برابر باشد).
- اندازه و هش SHA-256 با اطلاعات HTTPS API خود GitHub تطبیق داده می‌شوند. Release بدون digest، نسخهٔ قدیمی‌تر، بستهٔ ناقص یا فایل‌های اجرایی/مخفی رد می‌شوند.
- ساختار بسته از ماژول‌های تودرتو، فونت، استایل، صفحات HTML، فایل‌های JSON، تصاویر، `_locales` و الگوهای wildcard در `web_accessible_resources` پشتیبانی می‌کند، اما دسترسی به دامنه‌های غیر از اسنپ‌فود یا مجوزهای حساس مرورگر را رد می‌کند.
- جایگزینی فقط زمانی انجام می‌شود که هیچ تب اسنپ‌فودی در حال جستجو نباشد. نسخهٔ قبلی در پوشهٔ `previous` نگه داشته می‌شود تا در صورت خطا خودکار Rollback شود.

## دستورات توسعه و انتشار نسخهٔ جدید

```sh
npm test
npm run test:updater
npm run package
```

برای انتشار نسخهٔ جدید در گیت‌هاب:
۱. شمارهٔ نسخه را در `manifest.json`، `package.json` و `src/core.js` یکسان بالا ببر (مثلاً `1.1.0`).
۲. تغییرات را کامیت کن و تگ هم‌نام نسخه بزن (`git tag v1.1.0 && git push origin main --tags`).
۳. ورک‌فلوی GitHub Actions تست‌ها را روی Linux/Windows/macOS اجرا می‌کند و هر دو فایل `snappfood-assistant.zip` و `wheresmyfood-setup.zip` را در Release جدید منتشر می‌کند.
